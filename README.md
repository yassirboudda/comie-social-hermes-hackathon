# Comie · Social media + Hermes agents (hackathon)

Motion-design / demo pack for **Comie**’s social media integration and Hermes agents.

Built for the [Zernio × Swanbase hackathon](https://luma.com/wrgyhbwf?tk=tMp645) — adding GTM surface to Comie via **social account connect**, **ads management**, and agent-ready chat.

Partners / stack called out in the cut: [Zernio](https://zernio.com/) · [Swanbase](https://swanbase.co/)  
*(NVIDIA / Nebius logos are out of the edit — keep one-click deploy from the Comie demo.)*

## What Comie does here

Comie already automates **marketplace** accounts. This slice extends the same agent surface to:

- **Social media** — connect and operate accounts through Zernio
- **Ads** — connect and manage ad accounts / campaigns
- **Hermes** — GDPR dual-consent assistant that can read/reply in social inbox after both parties agree
- **Chat** — Comie chat can schedule content and drive social/ads tools

Agents reach marketplace, social, and ads accounts from one place.

## Brief for the motion design video

Generate a short motion design piece that:

1. Opens on Comie as the agent that already runs **marketplace** automation.
2. Introduces the hackathon GTM layer: **social connect + ads management** powered with [Zernio](https://zernio.com/), showcased at the [Luma event](https://luma.com/wrgyhbwf?tk=tMp645) with [Swanbase](https://swanbase.co/).
3. Cuts in the **connect social** clip — note multi-platform social **and** ads accounts.
4. Cuts in **Comie chat / Hermes** — dual consent, human-in-the-loop inbox, agent tools.
5. Cuts in **schedule content** — chat can schedule posts too.
6. Keeps **one-click deployment** energy from the main Comie demo; **do not** feature NVIDIA or Nebius logos.
7. Ends on: one agent surface for marketplace + social + ads.
